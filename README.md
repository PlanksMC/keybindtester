# ⌨️ Keybind Tester

Keybind Tester is a simple desktop application that allows you to test keyboard inputs in real time. It detects and displays every key you press, including modifier keys like Shift, Ctrl, Alt, and combinations.

## ✨ Features

- Real-time key detection
- Supports all standard keys
- Detects modifier keys (Shift, Ctrl, Alt)
- Shows key combinations (e.g. Ctrl + C)
- Lightweight and fast
- Simple, clean interface
